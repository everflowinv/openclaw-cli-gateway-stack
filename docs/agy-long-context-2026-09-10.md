# agy 1.2.0 长上下文验证

**结论：仍需保留网关的输入长度保护，并将计量单位从字符改为 UTF-8 字节。**
在本次 `stream-json` 输入／输出测试中，agy 1.2.0 会在约 192,000 字节处
截断传给模型的用户消息，随后仍返回 `SUCCESS`、退出码 0。调用方的 stdout
事件和 stderr 均未报告截断；截断标记只出现在本地保存的模型请求记录里。

## 版本与方法

- 日期：2026-09-10；macOS arm64；模型 `gemini-3.8-flash`，effort `low`。
- `agy --version` 为 `1.2.0`。官方安装脚本引用的
  [darwin_arm64 更新清单](https://antigravity-cli-auto-updater-974169037036.us-central1.run.app/manifests/darwin_arm64.json)
  当时同样返回 `1.2.0`；官方[变更记录](https://www.agy.dev/changelog?tab=cli)
  将它列为 9 月 10 日发布的 CLI 版本。
- 直接调用官方 agy，绕过网关现有的 190,000 字符保护。每次使用新的空工作目录
  和新会话，通过 stdin 发送一个 user 事件，完成后关闭 stdin。
- 合成文本中分布六个随机校验值，开头要求仅提取这些值，不调用工具；看不到的值返回
  `null`。校验值不在开头重复，原始输入文件也不在 CLI 工作目录内。
- 检查输出、退出码以及该测试会话 SQLite 数据库的 `gen_metadata` 生成请求。
  将请求中的输入前缀逐字节与原始文本比较，并核对内部截断标记，避免仅凭模型漏读
  就推断发生截断。
- 使用 `--disable-slash-commands`。同时传入的 `--mode plan` 被 CLI 提示为无效；
  这是六次测试中唯一的 stderr 警告，不是截断警告。测试没有工具调用。

## 实测结果

这里的“字符”按 Unicode 码点计数；中文用例混合中文填充、ASCII 指令和校验值。

| 输入 | UTF-8 字节数 | 文本块 | 正确校验值 | 模型请求保留的原始输入前缀 | 结果 |
|---|---:|---:|---:|---:|---|
| ASCII 180,000 字符 | 180,000 | 1 | 6/6 | 180,000 字节，完整 | SUCCESS / 0 |
| ASCII 190,000 字符 | 190,000 | 1 | 6/6 | 190,000 字节，完整 | SUCCESS / 0 |
| ASCII 250,000 字符 | 250,000 | 1 | 4/6 | 191,985 字节 | SUCCESS / 0 |
| ASCII 250,000 字符 | 250,000 | 4 | 4/6 | 191,985 字节 | SUCCESS / 0 |
| 中文混合 60,000 字符 | 174,990 | 1 | 6/6 | 174,990 字节，完整 | SUCCESS / 0 |
| 中文混合 90,000 字符 | 263,224 | 1 | 3/6 | 191,984 字节 | SUCCESS / 0 |

两次 ASCII 超限请求的保存记录都出现 `<truncated 58420 bytes>`，中文超限请求
出现 `<truncated 71645 bytes>`。这些数值包含 CLI 添加的消息框架，不能直接当作
原始用户输入丢失字节数。模型请求中的校验值缺失位置与回答的 `null` 一致。
原始输入仍完整存在于用户输入 step 中；仅检查会话是否保存了全文不足以发现问题。

官方 1.1.28 变更记录提到增加 headless truncation notifications，
但本次 1.2.0 的上述协议路径没有向调用方输出截断通知。

## 修正

- 完整拼接 system、历史消息和当前输入后，用 `Buffer.byteLength(prompt, "utf8")`
  检查大小，默认上限 **190,000 字节**，为 CLI 消息框架留出余量。
- 超限立即返回 HTTP **413**，错误信息包含 `Prompt exceeds` 和 `maximum input size`，
  供 OpenClaw 识别上下文过长；不启动 agy、不接受截断后的答案。
- 新配置 `AGY_CLI_GATEWAY_MAX_PROMPT_BYTES`；旧 `MAX_PROMPT_CHARS` 保留为低优先级
  兼容别名，其数值现在解释为字节。`/health` 暴露 `maxPromptBytes`。
- 增加中文、emoji、完整历史、流式请求与正常短请求的合成 CLI 集成测试。

不移除保护，也不把限制提升到模型宣传的 token 上下文窗口；本次发现的是 CLI
用户消息处理路径的字节限制。尚未测试其他模型、交互模式或未来版本，因此不将
这个边界宣称为所有模式的统一限制。六次实测摘要和二进制 SHA-256 见
[JSON 证据](agy-long-context-2026-09-10.json)，不含账户信息、完整系统提示词或原始日志。
